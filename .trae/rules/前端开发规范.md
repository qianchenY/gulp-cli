> 本文档用于 AI 代码生成时的参考，请严格遵循以下规范生成代码。

## 命名规范

| 类型         | 前缀      | 示例                                   | 说明                                |
| ---------- | ------- | ------------------------------------ | --------------------------------- |
| 全局页面容器     | `g-`    | `.g-hd`, `.g-bd`, `.g-ft`, `.g-sd`   | **整个页面级**的大容器，如头部、主体、页脚、侧边栏       |
| 模块组件       | `m-`    | `.m-hnews`, `.m-prolist`, `.m-about` | 具体的业务模块组件，首页和内页的模块都用 `m-`         |
| 公共工具类      | `c-`    | `.c-mt100`, `.c-bg1`, `.c-clearfix`  | common/util，全局复用的工具类（间距、背景、清除浮动等） |
| 安全范围       | `f-`    | `.f-box`                             | 安全宽度居中容器                          |
| JavaScript | `j-`    | `.j-nextshow`, `.j-lazy`             | JS交互钩子                            |
| 字体图标       | `icon-` | `icon-email`, `icon-search4`         | 字体图标类名                            |

> 💡 **首页 vs 内页命名差异**：
>
> - **首页**：每个模块外层包 `g-xxx` + 内层 `m-xxx`（例如 `<div class="g-habt"><div class="m-habt f-box">`）
> - **内页**：模块直接用 `m-xxx`（不需要外层包 `g-`）（例如 `<div class="m-about"><div class="f-box">`）

***

### 公共工具类 (`c-` 前缀)

`c-` = common/util，不与任何业务模块绑定，可全局复用。

| 类型      | 命名模式             | 典型示例                                  |
| ------- | ---------------- | ------------------------------------- |
| **间距类** | `c-` + 属性缩写 + 数值 | `c-mt100`, `c-pt100` (带响应式适配)         |
| **背景类** | `c-bg` + 序号      | `c-bg1` (半透明主题色), `c-bg2` (灰色背景)      |
| **重置类** | `c-no` + 属性缩写    | `c-nomg`, `c-nopd`, `c-nobg`          |
| **通用类** | `c-` + 属性缩写      | `c-clearfix`, `c-oh`, `c-pr`, `c-tsn` |

> 💡 **c- 类使用场景**：
>
> ```html
> <!-- 快速加边距 -->
> <div class="m-prolist c-mt100">
>
> <!-- 清除浮动 -->
> <div class="box-wp c-clearfix">
>
> <!-- 切换背景色 -->
> <div class="g-wp c-bg1">
> ```

> ⚠️ **重要：c- 类使用时机**
>
> - **生成单个模块时**：不要自行添加 c- 类，样式直接写在模块的 m- 类名下
> - **生成整个页面时**：如发现多个模块有重复样式（通用边距、背景等），可抽取为 c- 公共类，并放在 `/* .c-xx start */` 区块统一管理

## SCSS 规范

### 变量定义 (scss\_init.scss)

```scss
// 安全宽度（默认1400px，具体以设计图为准）
$width: 1400px;

// 颜色
$color: #00A2E9;    // 主色调，具体以设计图为准
$color2: #055DAF;   // 辅助色，具体以设计图为准

// 字体
$font-pr: 'PoppinsRegular', arial, helvetica, sans-serif; // 默认字体，具体以设计图为准
$font-pm: 'PoppinsMedium', arial, helvetica, sans-serif; // 中等粗，具体以设计图为准
$font-psb: 'PoppinsSemiBold', arial, helvetica, sans-serif; // 半粗，具体以设计图为准
```

### 核心函数

```scss
// 百分比宽度计算（基于安全宽度 $width）
@function get_w($w, $max: $width, $b: 100){
    @return math.div($w, strip-unit($max)) * $b + 0%;
}

// 使用示例
width: get_w(300);           // 300px在安全宽度中的百分比
width: get_w(370, 788, 100); // 基于788px的局部百分比（设计图模块非安全宽度时）

// vw单位计算
@function get_vw($size, $media: 1920) {
	@return math.div($size, strip-unit($media)) * 100vw;
}
```

### 混合宏 (Mixin)

```scss
// 字体大小（同时生成px和rem）
@include font-size(16);  // font-size: 16px; font-size: 1.6rem;

// 外边距
@include margin($top, $right, $bottom, $left);

// 过渡动画
@include transition(all, 500ms);

// 浮动
@include float(left);

// placeholder样式
@include placeholder(#333);
```

### 书写规范

#### 1. 层级嵌套（不超过3级）

```scss
.m-模块名{
    .box-item{
        .item-pic{
            // 最多3级，不要再嵌套
        }
    }
}
```

当前组件的样式必须都在 `.m-` 开头的类名下书写，避免影响其他组件的样式。

#### 2. 布局优先使用 Flex

```scss
.box-wp{
    display: flex;
    flex-flow: row wrap;        // 横排换行
    justify-content: flex-start;  // 左对齐（除非是一行两列布局，否则禁止space-between）
    align-items: flex-start;
    gap: 30px get_w(20);        // 垂直间距固定px，水平间距百分比
}
```

#### 3. 响应式媒体查询

**断点顺序**：从大到小，放在模块最底部

```scss
.m-模块名{
    // 默认样式（大屏桌面）
    
    @media screen and (max-width: 1440px){
        // 普通桌面
    }
    
    @media screen and (max-width: 991px){
        // 平板端
    }
    
    @media screen and (max-width: 640px){
        // 手机端
    }
    
    @media screen and (max-width: 375px){
        // 小屏手机端
    }
}
```

所有宽度、间距、字号等尺寸变化必须基于 `.f-box` 的特性进行等比缩放调整。

#### 4. 宽度计算

所有响应式宽度必须使用 `get_w($w)` 函数，默认基准 `$width`。

**禁止硬编码百分比或固定 px 值。**

`get_w()` 内只放纯数字，禁止传入 `%` 或 `px` 单位。

如果从设计图中获取模块宽度时其并非 `$width`，则在该组件下使用 `get_w($w, $base)` 函数根据指定安全范围换算。

#### 5. 高度计算

默认不为任何元素（`input`、`textarea`、`select` 等表单元素除外）设置固定高度 `height`。

如有需要 `height` 在布局中需要使用固定单位（`px`），并进行响应式适配。

**图片处理**：

```scss
img{
    display: block;
    width: 100%;
    height: auto;  // 自适应高度，不设置固定高度
}

// 懒加载类
.j-lazy{
    // 使用 data-original 属性
}
```

#### 6. 字体大小

必须使用 `@include font-size($value)` 混合宏，自动生成 px 和 rem 值。根元素字号为62.5%（10px）。

**禁止直接使用** **`font-size`** **属性。**

#### 7. 间距处理

| 间距属性           | 缩放方式          | 说明                             |
| -------------- | ------------- | ------------------------------ |
| `column-gap`   | `get_w()` 百分比 | 水平间距随安全范围换算                    |
| `margin-left`  | `get_w()` 百分比 | 左外边距                           |
| `margin-right` | `get_w()` 百分比 | 右外边距                           |
| `row-gap`      | 固定 px         | 垂直间距不要用百分比                     |
| `padding`      | 固定 px，响应式调整   | 避免使用 `get_w($w)` 导致间距随容器缩放过于剧烈 |

**断点缩放规则**：

|  默认间距  | 1440px | 991px | 640px | 375px |
| :----: | :----: | :---: | :---: | :---: |
|   ≥60  |   40   |   —  |   —   |   —   |
| 30\~59 | 30 |   —   |   —   |   —   |

> `—` 表示不调整，继承上一级；数值范围仅供参考，实际以设计图为准

#### 8. 字号和行高规范

- **1440px以上**：按设计图 1:1 还原，如设计图有小数字符值，四舍五入到最近的偶数值即可
- **响应式调整时**：所有断点的 `font-size` 和 `line-height` 必须使用 **偶数值**（14, 16, 18, 20, 22, 24...）
- 禁止使用 15, 17, 19, 21 等奇数值
- 响应式逐级递减时保持偶数值

**断点缩放规则**：

- 按默认字号数值**按需**指定各断点缩放值，`line-height` 同步缩放为偶数值
- **未指定的断点不调整**，继承上一级字号
- 缩放依据为**数值本身**，与语义无关

|  默认字号  | 1440px | 991px | 640px | 375px |
| :----: | :----: | :---: | :---: | :---: |
|   ≥50  |   30   |   24  |   —   |   —   |
| 24\~48 | 20\~24 |   —   |   —   |   —   |
| 16\~22 |   14   |   —   |   —   |   —   |

> `—` 表示不调整，继承上一级；数值范围仅供参考，实际以设计图为准

#### 9. 文本截断
列表模块
标题/描述等多行文本默认最多显示3行，实际行数参考设计图，按最大行数设置。

```scss
// 多行省略
.box-title{
    display: -webkit-box;
    -webkit-line-clamp: 3;  // 行数
    -webkit-box-orient: vertical;
    overflow: hidden;
    text-overflow: ellipsis;
}
```

#### 10. 富文本内容（描述 / 简介 / 文章）

新闻、案例、产品等详情页的文章内容，以及各模块的描述、简介等多行文本，均为富文本编辑器输出的内容，需遵循：

- 容器统一添加 `.m-desc` 类（使用其默认样式）
- 内部文本全部用 `<p>` 标签包裹，**不添加任何类名**
- 需要特殊样式时，仅可使用 `<em>`、`<strong>` 两个内联标签，特殊样式超过两个时才可以使用 `<p class="样式名"></p>` 标签。

```html
<div class="box-desc m-desc">
    <p><em>小标题</em></p>
    <p>普通段落，包含<strong>强调</strong>文本。</p>
</div>
```

#### 11. 字号 / 字体 / 颜色 默认继承

- 字体、字号、行高、颜色**默认继承**，**禁止在子元素上重复声明**（除非覆盖父级）
- `body` 设置全局默认 `font-family` / `font-size` / `line-height` / `color`
- `a` 单独设置默认样式与 hover 样式
- 子元素仅在需要**覆盖**父级时才声明对应属性
- 颜色用 SCSS 变量（`$color`），**禁止硬编码主题色**

#### 12. font-weight 与字体名对应

字体名已含粗细后缀时，**禁止重复声明 `font-weight`**：

| 字体名后缀      | 省略的 font-weight |
| ----------- | ---------------- |
| `Regular`   | `400`            |
| `Medium`    | `500`            |
| `SemiBold`  | `600`            |
| `Bold`      | `700`            |

只有**字体名是通用族**（`serif` / `sans-serif` 等）或未带粗细后缀时，才需要显式声明 `font-weight`。

```scss
// ❌ 字体已含 Regular，重复声明
font-family: 'PoppinsRegular', sans-serif;
font-weight: 400;

// ✅ 字体已含 Regular，省略 weight
font-family: 'PoppinsRegular', sans-serif;

// ✅ 通用族才需要 weight
font-family: serif;
font-weight: 700;
```

#### 13. 单位函数使用（vw 场景）

- **固定基准 vw 场景**（如 banner 大图文字、设计稿 1:1 还原，不需要再调整响应式）：用 `get_vw($size, 1920)`，**禁止直接写 `vw` 字面量**
- **响应式百分比场景**（基于安全宽度）：用 `get_w($w)`
- 两者**禁止混用**

#### 14. 样式分层原则（同类多状态）

轮播、Tab、分页等多状态组件，拆分为 **"公共层 + 序号层"**：

- **公共层 `.banner-text`**：放所有屏通用的布局 + 子元素基础样式（position、z-index、width、通用 font/color/padding 等）
- **序号层 `.banner-text1/2/3/4`**：只放当前屏的差异覆盖（字号、颜色、margin等单独样式）
- **禁止用 `:nth-child(N)`** 写差异，不利于维护和 EJS 循环场景
- **禁止把通用样式在每个序号层里重复写**

HTML 类名与 CSS 一一对应（`i=1` → `banner-text1`），不依赖选择器位置。

## 列表模块开发规范（新闻、产品等列表通用）

### 间距设置

- `column-gap` 使用 `get_w(xx)` 计算水平间距
- `row-gap` 使用固定像素值（默认30px，实际按照设计图调整）
- 垂直间距不要用百分比

### 标准多列布局

```scss
// 列布局（示例：5列）
.box-wp{
    display: flex;
    flex-flow: row wrap;
    justify-content: flex-start;
    gap: 30px get_w(20);  // row-gap固定px，column-gap百分比
}

.box-item{
    width: get_w(300);    // 单列宽度
}

// 响应式调整
@media screen and (max-width: 991px){
    .box-item{
        width: calc(50% - #{get_w(10)});  // 2列
    }
}

@media screen and (max-width: 640px){
    .box-item{
        width: 100%;  // 1列
    }
}
```

### 样式复用

列表项公共样式提取为独立的 `m-` 类（如 `.m-hnewsitem`），方便其他页面复用。

模块内的 `.xx-item` 只保留宽度、外间距等与布局相关的特有样式，公共样式继承自 `m-` 类。

```scss
// 提取公共样式（如：新闻列表项）
.m-hnewsitem{
    .item-title{
        @include font-size(18);
        line-height: 26px;
    }
}

// 页面内只写布局相关
.m-hnews{
    .box-item{
        width: get_w(500);
        margin-bottom: 20px;
    }
}
```

## JavaScript 规范

### 引入方式

- jQuery 优先引入（jquery-1.11.3.min.js）
- 然后引入第三方插件（swiper.min.js）
- 最后引入业务 JS（main.js, base.js）
- 首页所有 JavaScript 代码在主体内容结束之后、页脚部分之前统一添加，所有代码放在同一个脚本标签内
- 内页各模块的 JavaScript 代码紧跟在对应模块代码之后添加
- 如果 JavaScript 代码过长，可提取为独立的 JS 文件，放在 `/src/js/` 目录下，文件名必须以 `.js` 结尾

### 命名规范

#### 交互钩子类名

- JS 交互钩子以 `j-` 开头：`.j-nextshow`, `.j-lazy`, `.j-offset-top`
- 禁止使用 CSS 样式类作为 JS 选择器

#### JS 命名规则

- 变量名和函数名以驼峰命名法（`camelCase`），如 `userName`、`isActive`、`getUserInfo`
- 构造函数 / 类名以帕斯卡命名法（`PascalCase`），如 `TabManager`
- jQuery 对象变量以 `$` 前缀标识，如 `$this = $(this)`
- 除 jQuery 对象的 `$` 前缀外，命名不得使用其他特殊字符（如 `!`, `@` 等）

#### JS文件名

- 根据实际内容命名文件名，用`-`连接单词
- 文件名必须以 `.js` 结尾

### 常用交互类

| 类名                                | 功能        |
| --------------------------------- | --------- |
| `.j-nextshow`                     | 点击显示下一个元素 |
| `.j-lazy`                         | 图片懒加载     |

## 响应式适配策略

### 断点对照表

| 断点      | 设备    | 适配策略                                 |
| ------- | ----- | ------------------------------------ |
| 1440px+ | 大屏桌面  | 1:1 完全还原设计图，设计图有的内容不隐藏，字号、间距、行高1:1匹配 |
| 1440px  | 普通桌面  | 微调间距，缩小字体                            |
| 991px   | 平板端   | 列数减少（5→3，4→2），导航折叠                   |
| 640px   | 手机端   | 单列布局，元素居中，字体更小                       |
| 375px   | 小屏手机端 | 最小尺寸适配，间距紧凑                          |

### 尺寸缩放原则

| 属性         | 缩放方式                   | 示例                       |
| ---------- | ---------------------- | ------------------------ |
| width      | `get_w()` 百分比          | `width: get_w(300)`      |
| column-gap | `get_w()` 百分比          | `column-gap: get_w(20)`  |
| row-gap    | 固定 px                  | `row-gap: 30px`          |
| padding    | 固定 px，响应式调整            | `padding: 50px 20px`     |
| font-size  | `@include font-size()` | `@include font-size(16)` |

## 最佳实践

### 1. 命名语义化

- ✅ `.m-hnews`（home-news）
- ❌ `.m-news1`

### 2. 避免硬编码

- ✅ `width: get_w(300)`
- ❌ `width: 18.75%` 或 `width: 300px`

### 3. 层级控制

- ✅ 3级以内嵌套
- ❌ 深层次嵌套导致权重过高

### 4. 媒体查询位置

- ✅ 每个模块底部写自己的媒体查询，按断点从大到小分组
- ❌ 所有媒体查询集中在文件最后

### 5. Flex 布局

- ✅ `justify-content: flex-start`
- ❌ `space-between`（最后一行对齐问题，除非是一行两列的布局）

## 代码检查清单

开发完成后检查以下事项：

- [ ] 所有类名遵循 `g-`、`m-`、`c-`、`j-`、`icon-` 命名规范
- [ ] JS 钩子使用 `j-` 前缀
- [ ] 模块使用 `.f-box` 安全范围容器或在该容器内布局
- [ ] 在生成整个页面时，使用 `c-` 工具类处理通用间距、背景等，避免重复写样式
- [ ] CSS 层级不超过 3 级
- [ ] 列表项公共样式提取为独立 `m-` 类，模块内只保留布局样式
- [ ] 媒体查询按 1440px → 991px → 640px → 375px 顺序，放在模块最底部
- [ ] 1440px 以上完全还原设计图，设计图有的内容不隐藏，字号行高非偶数时四舍五入
- [ ] 字体使用 `@include font-size()` 混合宏，不直接写 `font-size`
- [ ] 响应式调整时所有断点的 `font-size` 和 `line-height` 使用偶数值（无 15, 17, 19, 21 等奇数值）
- [ ] 宽度使用 `get_w()` 函数，无硬编码 px/%
- [ ] Flex 布局使用 `flex-start` 而非 `space-between`（除非是一行两列布局）
- [ ] 图片使用 `width:100%; height:auto` 自适应，不设置固定高度
- [ ] 箭头、联系方式、社交媒体等使用字体图标，不使用 svg 图标
- [ ] `column-gap` 使用 `get_w()` 函数或百分比，`row-gap` 使用固定 px
